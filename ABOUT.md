# About this repository

This is a special GitHub repository: it has the same name as my account (`acogood`). GitHub treats a `<username>/<username>` repository as a **profile repository** and renders its `README.md` at the top of my profile page: https://github.com/acogood

A few things to know:

- The repository must stay **public** for the README to be shown on the profile.
- The profile "homepage" content is exactly the `README.md` in this repository — to update the profile, edit `README.md` and push.
- Everything else in this repository (including this file) is just documentation and is not displayed on the profile.
